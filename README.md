# Sürü Can - Hayvancılık Yönetim ve Takip Sistemi

Sürü Can, çiftçilerin hayvan varlıklarını dijital ortamda profesyonelce yönetebilmesi, verimlilik takibi yapabilmesi ve güncel piyasa verilerine anlık olarak erişebilmesi için geliştirilmiş bir **Android** uygulamasıdır.

## 🚀 Öne Çıkan Özellikler

* **Hayvan Kayıt ve Yönetimi:** Küpe numarası, ırk ve cinsiyet gibi detaylarla hayvanların sisteme kaydedilmesi.
* **Firebase Entegrasyonu:** Verilerin bulut altyapısında (NoSQL) güvenli ve esnek bir şekilde saklanması.
* **Anlık Piyasa Verileri:** Jsoup kütüphanesi kullanılarak canlı et ve süt fiyatlarının dış kaynaklardan çekilmesi.
* **Kullanıcı Yönetimi:** Güvenli giriş ve kayıt sistemleri.
* **Agile Metodolojisi:** Proje geliştirme sürecinde çevik yöntemler izlenerek modüler bir yapı oluşturulmuştur.

## 🛠 Kullanılan Teknolojiler

* **Dil:** Java (Android SDK)
* **Veritabanı:** Firebase Realtime Database
* **Kütüphaneler:** * `Jsoup` (Web Scraping / Veri Çekme)
    * `Firebase UI`
* **Versiyon Kontrol:** Git & GitHub
